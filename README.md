# 🐧 Linux & Git Тренажёр

Duolingo-style тренажёр команд Linux и Git — один самодостаточный HTML-файл, без сборки и зависимостей.

## Запуск

Просто открой `index.html` в браузере — или задеплой на Vercel / GitHub Pages как статический сайт.

## Структура

- `index.html` — точка входа (главная страница `/`)
- `linux-trainer.html` — та же игра отдельным файлом
- `linux-trainer/` — модульная версия (`index.html` + `style.css`, `data.js`, `app.js`, `sound.js`)
- `vercel.json` — настройки деплоя для Vercel

## Режимы

- 📇 Карточки — изучение команд и их описания
- 📝 Тест — проверка знаний
- ⌨️ Тренажёр — сборка команд по словам как в Duolingo
