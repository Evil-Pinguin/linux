# Linux • Bash • Git Тренажер

Duolingo-style тренажер командной строки: учит командам Linux, основам языка Bash
(пайпы, перенаправление вывода, переменные) и Git — от базовых команд до терминов
(HEAD, origin, staging area, форк, пул-реквест и т.д.).

## Запуск

Просто открой `linux-trainer.html` (или `linux-trainer/index.html`) в браузере —
сервер не нужен, весь CSS и JS встроены в файл.

Для статических хостингов (Vercel, GitHub Pages): корневой `index.html`
автоматически перенаправляет на `linux-trainer.html`.

## Режимы

- **📇 Карточки** — 60 карточек (команды и термины) с тиндер-свайпами:
  вправо «знаю», влево «не знаю», вниз «повторить». Статусы, позиция и фильтр
  сохраняются на устройстве — можно продолжить с того же места.
  Фильтры по темам: Все / Linux / Bash / Git / Термины
- **⌨️ Тренажер** — задачи «собери команду из слов»: 44 вопроса
- **🔡 Тренажер 2** — набери ответ по буквам, как в Duolingo: правильная буква
  встаёт в пропуск, неправильная вспыхивает красным и не ставится (минус жизнь)
- **📖 Справочник** — словарь всех команд и терминов + пошаговый гид
  «Публикация проекта в Git»: от генерации и привязки SSH-ключа до `git push`
- **📝 Тест** — 31 вопрос с вариантами ответов и объяснениями

Урок — 10 случайных вопросов, 5 жизней. Прогресс (XP, статусы карточек,
позиция в колоде, фильтр) сохраняется в localStorage; если браузер блокирует
хранилище (встроенные просмотры/iframe), приложение работает в пределах сессии.

## Структура

```
linux-trainer/
├── index.html    — разметка + встроенные стили/скрипты (самодостаточный файл)
├── data.js       — команды, термины, вопросы тренажера и теста
├── app.js        — логика режимов
├── sound.js      — звуки (Web Audio API)
├── style.css     — стили
└── build.py      — пересборка index.html и linux-trainer.html из data/sound/app/style
```

После правок `data.js`, `app.js`, `sound.js` или `style.css` запусти
`python3 build.py` — он обновит встроенные блоки в `index.html`
и синхронизирует одиночный `linux-trainer.html`.
